# Project overview
Your goal is to build a stremlit app that allow users to scrape a website and add the data to airtable database , it should be able to login and handle pagination , also parsing the content with Ollama .
You will be using the following libraries:
- streamlit
- airtable-python-wrapper
- requests
- bs4
- langchain
- langchain-ollama
- AgentQL
- playwright
